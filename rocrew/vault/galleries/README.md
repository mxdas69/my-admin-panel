# Galleries

Annotated screenshots of real games, grouped by game or by topic. Agents study them before designing something similar. The owner can drop screenshots into `vault/img/` and add an entry; Pulse and Splash add entries while researching.

## Entry format

```markdown
### Shops: rough frame, clear odds
![](../img/example-shop.png)

**Shows:** what's on screen, factually (layout, prices, colors, buttons).
**Why it works:** the design reason it helps players or sales.
**Avoid:** what not to copy.
**Steal:** the one idea to reuse, in a sentence.
```

## Rules
- Only use screenshots you took yourself or that the owner provided.
- Never copy another game's characters, logos or art into ours. Steal ideas and patterns, not assets.
- Keep one file per game or topic, for example `galleries/shops.md` or `galleries/<game name>.md`.
